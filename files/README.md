# 刹那 / SETSUNA

> 一瞬を制す者だけが生き残る。速度・精度・抑制 — 反射神経のすべてを鍛えるシネマティック反射神経ゲーム。

スマホ・ブラウザだけで動く、依存ライブラリ・外部アセットゼロの単一HTMLゲームです。ネオンノワール調のハリウッド・カラーグレーディングで、タップ／回避／スワイプの3要素で反射神経を鍛えます。

## ▶ 遊ぶ

**ライブデモ:** `https://<あなたのユーザー名>.github.io/setsuna/`
（GitHub Pages を有効化すると上のURLで公開されます。下の「公開手順」参照）

## 難易度

タイトル画面で **EASY / NORMAL / HARD** の3段階から選べます（選択は次回起動時も保持）。

| 難易度 | 出題ペース | 反応猶予 | 妨害（赤・矢印） |
|--------|-----------|---------|----------------|
| EASY（入門） | ゆっくり | 長い | 少なめ |
| NORMAL（標準・初期設定） | 速い | 短い | 多い |
| HARD（極限） | 非常に速い | とても短い | 非常に多い・密集 |

対戦時は**ホストの難易度で両者が統一**されます（ゲスト側は自動で合わせられます）。

## 遊び方

| 要素 | 操作 | 内容 |
|------|------|------|
| ◎ オーブ | **タップ** | 縮む輪がオーブに重なる瞬間にタップ。タイミングで PERFECT / GOOD / EARLY 判定 |
| ✕ ハザード | **押さない** | 赤いトゲは押すとライフ減少。触れずにやり過ごせば加点 |
| ➤ アロー | **スワイプ** | 表示された方向へスワイプ。反応速度(ms)が記録される |

- **コンボ**でスコア倍率が上昇。一定コンボごとにライフ回復。
- **FOCUSゲージ**が満タンで⚡発動 → スローモー（バレットタイム）に。
- リザルトで **SS〜D** のランク、反応速度、精度、最大コンボを表示。ワンタップでシェア。

## ⚔ 2人対戦（リアルタイム）

別々の端末同士でリアルタイムに対戦できます。

1. 片方がタイトルで「⚔ 対戦ルーム作成」→ 4文字のコードが表示される
2. もう片方が「🔗 コードで参加」→ コードを入力して接続
3. 接続できたら自動で同時スタート。互いのスコア・コンボ・ライフが画面上部にリアルタイム表示され、決着すると WIN / LOSE を判定

**仕組み**：両端末は同じシードから**完全に同一の出題列**を生成するため、まったく同じ課題で勝負できます。判定は各自の端末で行うので通信遅延が自分の操作に影響しません（遅延は相手の状況表示が少し遅れるだけ）。接続には [PeerJS](https://peerjs.com/) の無料シグナリングサーバーを利用します（P2P接続なので対戦データ自体はサーバーを経由しません）。

> 同じWiFiやモバイル回線同士だと安定します。一部の対称NAT環境では接続できない場合があります（その際は自前のTURNサーバーが必要）。

## 特徴

- 🎬 シネマティック演出（レターボックス、フィルムグレイン、スピードライン、衝撃波）
- ⚔ リアルタイム2人対戦（WebRTC / PeerJS・決定論シードで完全同一の出題）
- 🔊 Web Audio API によるリアルタイム音声合成（音声ファイル不要）
- 📱 モバイルファースト（セーフエリア対応・触覚フィードバック）
- ♿ `prefers-reduced-motion` 対応・ミュート・ポーズ
- 💾 ベストスコアの永続化
- 📦 単一ファイル・依存ゼロ

## ローカルで動かす

`index.html` をブラウザで開くだけです。ローカルサーバ経由で開きたい場合:

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 技術

- Vanilla JavaScript（フレームワークなし）
- Canvas 2D による描画
- Web Audio API（効果音はすべてコード合成）
- 品質保証: ブラウザ環境をモックしてゲームループを仮想時間で実走させるヘッドレステストを使用
